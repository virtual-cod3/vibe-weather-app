# 🌤️ Vibe Weather

A clean and responsive weather application that provides real-time weather information
for any location using the OpenWeather API.

## ✨ Features

* 🌡️ Current temperature
* 🤗 Feels-like temperature
* 🌦️ Weather condition and weather icon
* 💧 Humidity
* 💨 Wind speed and direction
* 📊 Atmospheric pressure
* 👁️ Visibility
* ☁️ Cloud coverage
* 🌅 Sunrise and sunset
* 📅 5-day weather forecast
* 📍 Current location weather
* 🌙 Dark / light mode
* 🔄 Refresh weather data
* 📱 Responsive design for mobile, tablet, and desktop
* ⚡ Loading and error handling
* 🎨 Dynamic backgrounds based on weather conditions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* OpenWeather API

## 🚀 How to Use

1. Open the application using the live demo link.
2. Enter a city name in the search box.
3. Click **Search** to view the weather.
4. Use **Use My Location** to get weather based on your current location.
5. Use the **Refresh** button to update the weather.
6. Use the 🌙 button to switch between light and dark mode.

## 🔌 API

This project uses the **OpenWeather API** to retrieve real-time weather and forecast data.

The application uses the API to display:

* Current weather conditions
* Temperature
* Humidity
* Wind information
* Visibility
* Sunrise and sunset
* 5-day forecast

Vibe Weather is designed to work across different screen sizes, including:

* 📱 Mobile phones
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop screens

## 🎨 Weather-Based UI

The application dynamically changes its background based on the current weather condition, including:

* ☀️ Clear weather
* ☁️ Cloudy weather
* 🌧️ Rain
* ⛈️ Thunderstorms
* ❄️ Snow
* 🌙 Night
